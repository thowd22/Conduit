## Description

The terminal-looking UI layer (Text, InteractiveText, Surface, Input), the semantic element tree with hit testing, and the agent-drivable test driver (in-app automation server, conduit-test CLI, MCP server, screenshots). Built early so every later feature ships with E2E tests. Exit: an agent can launch Conduit, inspect, click, type and screenshot.
